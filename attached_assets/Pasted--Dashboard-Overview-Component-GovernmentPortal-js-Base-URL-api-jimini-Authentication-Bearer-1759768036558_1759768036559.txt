🎯 Dashboard Overview
Component: GovernmentPortal.js
Base URL: /api/jimini
Authentication: Bearer Token + Tenant/Session headers

4 Main Tabs:

📋 Decision Logs - View and filter policy decisions
📝 Rules - YAML-based rule authoring with validation
✅ Approvals - Policy proposal workflow
📊 Coverage - Rule effectiveness statistics
✅ Currently Working Endpoints (6)
Your backend already proxies these to the external Jimini service:

✅ GET  /api/jimini/rules              - Returns 29 active rules
✅ GET  /api/jimini/approvals          - Returns approval queue  
✅ GET  /api/jimini/decisions/stats    - Returns coverage stats
✅ GET  /api/jimini/health             - Service health check
✅ GET  /api/jimini/metrics            - System metrics
✅ POST /api/jimini/evaluate           - Policy evaluation (used by SecureLLMWrapper)

🔍 Key Findings
Dashboard expects all responses to use items array format
Pagination uses page and size query params
Timestamps must be ISO8601 format
Masked PII shown in separate request_masked/response_masked fields
Authentication via Bearer token with tenant headers
