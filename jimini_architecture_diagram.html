💡 Integration Pattern
Dashboard calls Jimini's /v1/evaluate endpoint to validate AI requests/responses before displaying to users or sending to AI providers

🔍 What Jimini Evaluates

🔒 PII Protection
SSN, driver's licenses (all 50 states), credit cards, phone numbers, email addresses
🏥 HIPAA Compliance
Medical record numbers, patient identifiers, health information
⚖️ CJIS Compliance
Criminal justice data, fingerprints, arrest records
🌍 GDPR Protection
European citizen data, passport numbers, national IDs
🔑 Credential Detection
API keys, passwords, tokens, database credentials
🤖 Microsoft Copilot
Illinois-specific protections for state government AI use

📡 API Integration Example

// Dashboard makes API call to Jimini
const response = await fetch('https://jimini-security-gateway.replit.app/v1/evaluate', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer jimini-api-key-10062025',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    text: userInput,
    direction: 'request',
    context: { user_id: '12345', source: 'dashboard' }
  })
});

const decision = await response.json();
// decision.action: 'allow', 'flag', or 'block'
// decision.violations: Array of detected issues
// decision.safe: boolean
